# Lassi banane


Lassi banane 

[![](../_resources/unknown_filename.227.jpeg =318x425)](http://icu.linter.fr/750/382730/5972240820/lassi-banane.jpg)

**Ingrédients** / pour 2 personnes

* Mixeur
* 2 bananes
* 200 ml de [lait](http://cuisine.journaldesfemmes.com/encyclopedie/fiche_composant/286/lait.shtml)
* 100 ml [yaourt](http://cuisine.journaldesfemmes.com/recette-yaourt) nature
* 1 cuillère à soupe de [miel](http://cuisine.journaldesfemmes.com/encyclopedie/fiche_composant/225/miel.shtml)

**Préparation** 

1. Peler les bananes, les couper en morceaux. Mettre les morceaux de bananes dans le bol à mixeur.

* Verser le yaourt nature dans le bol à mixeur avec les bananes.
* Mixer les bananes jusqu'à obtenir un liquide épais. Ajouter le miel et le lait. Mixer le tout !
